# Security Policy

## Supported Versions

Travel TR is an educational full-stack web application developed as a portfolio project.

| Version | Supported |
|---------|-----------|
| 1.0.0 | ✅ Yes |
| Earlier versions | ❌ No |

Security updates are provided on a best-effort basis. Regular maintenance and security patches are not guaranteed.

## Reporting a Vulnerability

If you discover a security vulnerability in Travel TR, please report it privately.

**Do not create a public GitHub issue containing sensitive vulnerability details.**

Instead, use GitHub's private vulnerability reporting feature, if enabled, through the repository's **Security** tab.

Reports should include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- The potential security impact.
- Suggested fixes, if available.

Reports will be reviewed on a best-effort basis.

## Security Considerations

Travel TR is a demonstration project and is not intended for production use without additional security testing and configuration.

The project includes authentication, authorization, input validation, and other security measures, but these do not guarantee complete protection.

Please do not use real payment information or sensitive personal data when testing the application.
